这是一篇示例文章，用来展示编辑器保存后的文章在博客页面的渲染效果。

## 文字样式

支持 **加粗**、*斜体*、~~删除线~~、`行内代码`，也支持 [外部链接](https://vitepress.dev/zh/)。

## 引用

> 引用块会显示左侧的竖线标记。
> 可以有多行内容，适合写提示或补充说明。

## 代码块

```js
// 编辑器内置 CodeMirror 编辑器，支持语法高亮
export function greet(name) {
  return `Hello, ${name}!`
}
```

## 表格

| 功能 | 说明 | 状态 |
| --- | --- | --- |
| 全屏编辑 | 编辑器铺满整个浏览器视口 | ✅ |
| 文件树 | 浏览/加载/删除仓库文章 | ✅ |
| 图片直传 | 粘贴、拖拽多图上传 | ✅ |
